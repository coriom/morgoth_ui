## 2. `GET /api/objectives/stats` — Response Shape Unknown

The endpoint exists but the response shape is not documented.

**Expected response shape for the dashboard `StatusBar`:**
```json
{
  "total": 12,
  "by_status": {
    "pending": 6,
    "in_progress": 3,
    "completed": 2,
    "failed": 1,
    "blocked": 0
  },
  "auto_completed": 5
}
```

**`auto_completed`** = objectives with `generated_by === "morgoth"` and `status === "completed"`.  
This enables a true auto-completion ratio rather than the total completion ratio the UI currently uses.

**Where to add:** `morgoth/memory/persistent_memory.py` → `get_objectives_stats()`.
